# Комплекти занять і навчальні точки

Комплект складається з одного головного заняття та довільної кількості
навчальних точок. Кожна точка зберігається як окреме заняття і має власні
назву, час, місце, опис, інструкторів, нагадування та кастомні параметри.

Кастомні поля синхронізуються з головного заняття в навчальні точки, якщо в
обох заняттях збігаються стабільний ID поля (`code`) і тип. Окремі поля точки
не змінюються. Якщо спільне значення очищене в головному занятті, воно також
очищається в усіх точках.

## Залежні поля

Головне заняття керує календарною датою і підрозділом усього комплекту.
Навчальна точка не дозволяє редагувати ці поля безпосередньо та надає перехід
до редактора головного заняття. Під час перенесення комплекту кожна точка
зберігає власний час початку й завершення.

## Поля Firestore

Зв'язок зберігається без окремої колекції:

- `linkedSetId` — спільний ідентифікатор комплекту;
- `mainLessonId` — ідентифікатор головного заняття;
- `linkedLessonRole` — `main` або `learningPoint`.

У головного заняття `linkedSetId` і `mainLessonId` дорівнюють його ID. Старі
документи без цих полів залишаються звичайними незалежними заняттями.

Шаблон головного заняття містить впорядкований список `linkedTemplateIds`.
Зміна складу шаблону не змінює вже створені комплекти.

## Операції

- створення головного заняття і вибраних точок виконується одним Firestore
  batch-записом;
- перед створенням адміністратор може виключити непотрібні точки;
- наявне незалежне майбутнє заняття можна прилінкувати як точку;
- точку можна від'єднати зі збереженням заняття або видалити;
- при видаленні головного заняття адміністратор обирає: видалити весь комплект
  або залишити точки як незалежні заняття.

Зв'язки однорівневі: навчальна точка не може мати власних дочірніх точок.
Повторювані заняття для комплектів не підтримуються.
